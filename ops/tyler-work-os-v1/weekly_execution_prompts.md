# First 7 Weekly Execution Prompts

1. **Money-Now Focus Prompt**: "List the top 5 revenue actions for this week ranked by expected cash in <14 days, with owner and due date."
2. **Follow-Up Integrity Prompt**: "Identify every lead/project with follow-up due in the next 48 hours and generate exact outreach messages."
3. **GO/HOLD Governance Prompt**: "Review all active items and set GO/HOLD with one-sentence reasoning and kill criteria check."
4. **Build Queue Compression Prompt**: "Select one build item to ship this week, define the minimal scope, and output PR-ready task steps."
5. **Harbourview Launch Control Prompt**: "Verify latest workflow evidence, flag missing run IDs, and output launch risk status."
6. **Proof Asset Acceleration Prompt**: "Convert recent wins/evidence into 3 proof assets with links, claim statements, and usage location."
7. **CEO Weekly Review Prompt**: "Summarize wins, misses, blockers, and next-week commitments with cash impact and required Tyler actions."
