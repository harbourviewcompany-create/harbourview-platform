# Supplier CRM import data

Place the five supplier CRM CSV files in this directory only for local or controlled database imports:

- `crm_supplier_company_rollup.csv`
- `crm_supplier_contacts.csv`
- `crm_supplier_email_outreach.csv`
- `crm_supplier_linkedin_outreach.csv`
- `crm_supplier_phone_outreach.csv`

These CSVs contain supplier outreach CRM data and must not be committed to the public repository. Use the validation script before import.
