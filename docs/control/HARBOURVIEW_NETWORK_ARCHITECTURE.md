# Harbourview Network Architecture

## Real Objective
Build Harbourview Network as a controlled global cannabis commercial access graph combining public-safe discovery, reviewed inquiry routing, country/pathway intelligence and private admin intelligence.

## Selected Direction
Global Cannabis Access Graph.

## Why This Wins
- Stronger strategic defensibility than a marketplace or directory.
- Country/pathway intelligence creates durable differentiation.
- Public/private DTO separation supports compliant scaling.
- Relationship-routing avoids commodity lead-gen positioning.

## Platform Pillars
1. Country and pathway spine
2. Category taxonomy
3. Public-safe discovery
4. Wanted requests
5. Qualified introduction requests
6. Commercial intelligence
7. Memberships
8. Admin review and claim control
9. DTO boundary enforcement
10. Audit-first operational model

## Public / Private Boundary
Public routes expose approved DTOs only. Admin routes may access review metadata, routing notes and evidence references only when protected by existing admin controls.

## Admin Model
Expected roles:
- admin
- operator
- analyst
- viewer

## Build Sequence
1. Architecture
2. Static Foundation
3. Admin Review Shell
4. Database/Auth
5. Globe/Atlas
6. Monetization

## Pass 1 Non-Goals
- No database changes
- No auth changes
- No route rewrites
- No live persistence
- No monetization flows
- No Globe/Atlas implementation
