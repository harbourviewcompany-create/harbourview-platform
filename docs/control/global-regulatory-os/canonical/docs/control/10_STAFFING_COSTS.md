# Staffing and Cost Checkpoints

## Phase 0

8–12 weeks; approximately $600,000–$1.4 million loaded cost. Product owner, programme lead, principal architect, 2–3 senior engineers, ontology lead, 2 analysts, fractional security/privacy and external specialists.

## Phase 1

4–6 months after Phase 0; approximately $2–$4.5 million incremental. Engineering 10–16; analysts 4–8; specialist reviewers 1–3 equivalents; security/QA/infrastructure 2–4; product/design/programme 3–5.

## Phases 2–4

Approximate annual run rate $6–$15 million. Product/engineering/data 20–35; analysts/reviewers/translators/specialists 15–35; retained counsel network; dedicated security, quality, implementation and customer functions.

## Institutional global scale

Approximate annual run rate $15–$35 million and three-year build range $30–$65 million. Lower spend can create valuable modules but cannot honestly support complete, reviewed, operational global coverage.

## Cost gates

No material feed contract before rights/value review; no second region before residency/customer need; no graph database without measured need; no custom model training before evaluation data and commercial value; no transaction fee layer before legal review; reforecast each phase against quality, coverage and revenue evidence.
