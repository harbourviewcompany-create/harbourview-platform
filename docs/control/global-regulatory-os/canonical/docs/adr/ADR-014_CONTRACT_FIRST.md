# ADR-014: Contract First

**Status:** Accepted  
**Date:** 2026-07-31

## Decision

Version API, event and data contracts before user-interface or service coupling.

## Consequences

Allows independent implementation and compatibility testing.

## Rejected alternative

UI-embedded business logic was rejected.

## Verification

The relevant contracts, migration tests, authorization tests, lineage tests or operational evidence must be attached to the phase release record.
