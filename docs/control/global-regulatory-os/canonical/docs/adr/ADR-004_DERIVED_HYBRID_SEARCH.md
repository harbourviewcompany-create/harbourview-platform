# ADR-004: Derived Hybrid Search

**Status:** Accepted  
**Date:** 2026-07-31

## Decision

Use lexical and semantic retrieval with authorization-filtered, rebuildable indexes.

## Consequences

Legal research needs identifiers and exact phrases as well as conceptual matching.

## Rejected alternative

Vector-only and keyword-only retrieval were rejected.

## Verification

The relevant contracts, migration tests, authorization tests, lineage tests or operational evidence must be attached to the phase release record.
