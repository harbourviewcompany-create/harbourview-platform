# ADR-013: Regional Cells on Verified Need

**Status:** Accepted  
**Date:** 2026-07-31

## Decision

Start with one primary and DR region; add residency cells for verified legal, contractual, latency or resilience requirements.

## Consequences

Controls cost and distributed-data complexity.

## Rejected alternative

Default global multi-write architecture was rejected.

## Verification

The relevant contracts, migration tests, authorization tests, lineage tests or operational evidence must be attached to the phase release record.
