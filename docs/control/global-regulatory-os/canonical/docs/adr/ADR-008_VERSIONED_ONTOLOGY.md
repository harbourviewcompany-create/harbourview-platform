# ADR-008: Versioned Ontology

**Status:** Accepted  
**Date:** 2026-07-31

## Decision

Canonical concepts and jurisdiction mappings are effective-dated and immutable after approval.

## Consequences

Historical determinations must resolve using the ontology in force at that time.

## Rejected alternative

Mutable lookup tables were rejected.

## Verification

The relevant contracts, migration tests, authorization tests, lineage tests or operational evidence must be attached to the phase release record.
