# Engineering Epics and Tickets

This directory contains 96 numbered implementation tickets across eight phases. Dependencies are explicit. Phase sequencing does not narrow the global target state.

A ticket is complete only when its acceptance criterion and referenced verification evidence are attached to the release record. `P1-001..P1-011` means every ticket in that inclusive phase range.

The CSV index is suitable for import into Linear, Jira, Airtable or a planning database.
