# Source Onboarding Checklist

## Authority and scope

- [ ] Issuing authority verified.
- [ ] Jurisdiction and legal-authority level recorded.
- [ ] Source classes and topics recorded.
- [ ] Official versus secondary status recorded.
- [ ] Historical coverage and known omissions documented.

## Rights and access

- [ ] Terms reviewed and dated.
- [ ] Automated collection rights confirmed.
- [ ] Storage rights confirmed.
- [ ] Redistribution and attribution requirements recorded.
- [ ] Licensed/restricted fields marked.
- [ ] Credential owner and rotation policy recorded.

## Technical configuration

- [ ] Endpoint and allowed hosts registered.
- [ ] Private/reserved network destinations blocked.
- [ ] Rate limit and schedule configured.
- [ ] Expected content types configured.
- [ ] Parser and fallback source assigned.
- [ ] Freshness SLA and escalation owner assigned.
- [ ] Duplicate and canonical-identifier rules tested.

## Quality and operations

- [ ] Representative fixtures captured.
- [ ] Parser output reviewed.
- [ ] Version/diff behavior tested.
- [ ] Effective dates and identifiers validated.
- [ ] Failure and source-change alert tested.
- [ ] Coverage limitations published.
- [ ] GO/HOLD decision recorded.
