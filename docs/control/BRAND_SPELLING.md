# Harbourview brand spelling

**Authority:** README brand table + this file. Prefer README for the short form.

## Canonical forms

| Form | Context |
|------|---------|
| **Harbourview** | Product name, company name, prose, PR titles, agent copy |
| **HARBOURVIEW** | UI wordmark only |
| `harbourview` | Vercel project slug, lowercase identifiers |
| `harbourview-platform` | GitHub repository name |
| `harbourviewcompany-create` | GitHub org |
| `https://harbourview.vercel.app` | **Only** canonical production web domain |

Spelling is **Harbour** (with **u**), not American *Harbor*.

## Forbidden / non-canonical

Do not use these in docs, PRs, agent handoffs, or operator notes:

- Harborview, Harbor View, Harborview Platform
- OurView, ourview, ourview.vercel.app
- Truncated mobile browser chrome (e.g. `ourview.vercel.app` when the full host is `harbourview.vercel.app`)
- Historical aliases as “current production” without labelling them historical: `harbourview-platform.vercel.app`, `harbourview-nu.vercel.app`
