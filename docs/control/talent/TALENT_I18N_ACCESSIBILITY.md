# Talent Internationalization and Accessibility

Anchors: TAL-011, TAL-029, TAL-046, TAL-089–090; TAC-033.

Store original source language/content separately from normalized/search/localized values. Translation never replaces the authoritative original. Jurisdictions use country/subdivision/locality and explicit timezone semantics where deadlines/scheduling depend on local time.

P0 accessibility evidence requires semantic headings/landmarks, labels and descriptions, accessible Find Jobs/Find Talent mode control, keyboard-only operation, focus-visible, focus restoration, result-count/live status announcements, error association, reduced motion, non-color-only status communication, practical 44px touch targets and contrast checks.

Required mobile viewports: 375×812, 390×844, 430×932. Desktop: 1280×800 and 1440×900.

Accessibility failures on primary search/apply/disclosure workflows block GO.
