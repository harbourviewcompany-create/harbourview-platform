# Harbourview Talent Control Pack

Audited base: `04e306d520d69d746a5099bf778dc253296710a3` (2026-08-14).

This directory freezes the execution controls for Harbourview Talent before runtime implementation. `TALENT_SCOPE_LEDGER.md` is the controlling scope document. Supporting documents elaborate ledger capability IDs and acceptance criteria; they do not silently narrow or replace them.

Core rule: no approved Talent capability may disappear during implementation. Any capability not implemented in the active phase remains represented with its target architecture, dependency, preserved foundation, tests, evidence obligation, phase, and status.

Documents in this pack cover current-state discovery, canonical architecture, identity resolution, taxonomy, provenance, employer authority, privacy and consent, source governance, requisitions/jobs, Professional Passport and credentials, applications/documents, search, matching/eligibility, API/DTO boundaries, RLS, trust/safety, retention/data rights, entitlements, i18n/accessibility, performance/observability, tests, search evaluation, migration/replay, visual evidence, acceptance criteria, evidence logging, and final GO/HOLD release control.
